# biomarker-prediction
Reimplemented a graph-based pipeline on a 4,704-feature dataset, applying module detection and centrality ranking to identify a 1,021-node network and its top 20 candidate features.

Actual study:
Rastegari M, Salehi N, Zare-Mirakabad F. Biomarker prediction in autism spectrum disorder using a network-based approach. BMC medical genomics. 2023 Jan 23;16(1):12.
https://link.springer.com/article/10.1186/s12920-023-01439-5
